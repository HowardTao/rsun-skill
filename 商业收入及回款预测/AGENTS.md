# AGENTS.md — 商业收入及回款预测

本目录是一个**可分发的 AI 技能包**(遵循 Agent Skills 规范),不是应用工程。

`SKILL.md` 是**权威执行文档** —— 口径、流程、列结构一律以它为准。本文件只补充一件事:**改这个技能时必须知道、但容易踩坑的红线**。

## 红线(绝不可自行决定)

0. **遇到任何不确定、歧义或信息缺失,禁止自行假设或发散**,必须直接向用户提问澄清 —— 问题越详细、越具体越好。**口径类问题尤其如此。**
1. **基准日与门店必须由用户提供并确认**,不得假设默认值。门店口语别名优先查 `references/dataset-and-rules.md` 的映射表;**别名表未覆盖时用 `CONTAINS` 筛选去重确认全称,不得猜测**。
2. **收入/回款预测必须先确认预测年度**(默认当前自然年,可自定义),未明确前不得生成任何表。
3. **`合同状态` 字段只展示,绝不作为筛选条件**。在执行/未执行一律用日期窗口判定:
   - 在执行 = 起租日 ≤ 基准日 ≤ 到期日(到期日 = 基准日的必须包含)
   - 未执行 = 起租日 > 基准日 且 起租日 < 到期日
4. **铺位类型默认「正铺 + 多经」**,仅在用户明确指定单一类型时才筛选。
5. 口径调整**必须先与负责人确认**,再改代码与文档,并记入 `PROJECT_MEMORY.md`「已确认的决策」与变更日志。

## 取数约定

- 一律用 `guancli ds preview --filter`;**禁用 `ds execute-sql`**(该环境报 Spark `PARSE_SYNTAX_ERROR`)
- 日期过滤条件的时间部分**必须写 `00:00:00`**(字段为零点时间戳,LE/GE 构成闭区间)
- 合同清单:`--limit 2000`;结果行数达到 limit 时须向用户说明可能被截断
- **应收明细强制分批**:按合同号 `IN` 每 50 个一批(`--limit 10000 -f json`),单批达 limit 视为截断须拆小重取,**禁止一次性全量取数**
- `ds preview` 无 `-o` 参数,用 shell 重定向落盘 `/tmp/`

## 脚本规范

- **参数必填,禁止硬编码业务值**:基准日 / 预测年度 / 门店等一律通过命令行参数传入
- 唯一第三方依赖 `openpyxl`;新增依赖须同步声明到根 `README.md`「环境要求」与本技能 `SKILL.md`
- 产物输出到**用户当前工作目录**的 `output/`,命名 `<门店简称><表名>_<基准日>.xlsx`
  - **绝不写入技能安装目录**(技能目录是分发包,不是工作区)
- 生成后交付给用户,并在回复中给出**校验结果与关键统计汇总**(交付方式由客户端决定,不要绑定某个客户端特有的工具名)
- Python 解释器优先 `~/.workbuddy/binaries/python/envs/default/bin/python`,不存在则用本机 Python 3

## 关于 PROJECT_MEMORY.md

它是**开发者本地**的口径溯源与变更记录,**不是运行依赖**:

- **改这个技能时**:必读 —— 口径的「为什么」和已确认决策都在里面
- **仅执行任务时**(取数、生成临时表):**不要读它**,口径一律以 `SKILL.md` 为准
- 技能分发到其他机器后,执行只依赖 `SKILL.md` / `references/` / `scripts/`

## 改完之后按这个顺序同步

`SKILL.md`(口径/流程)→ 脚本头部注释 → 本目录 `README.md` → `PROJECT_MEMORY.md` 变更日志 → 根 `README.md`(仅技能增删时)
