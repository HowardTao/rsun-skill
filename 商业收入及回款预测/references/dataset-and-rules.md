## 在执行合同判定口径（唯一正确口径）

**在执行 = 起租日 ≤ 基准日 ≤ 到期日（日期窗口判定），包含正铺和多经。**

筛选条件（guancli ds preview --filter，AND 组合）：

```
--filter "门店名称 EQ <门店全称>"
--filter "起租日 LE <基准日> 00:00:00"
--filter "到期日 GE <基准日> 00:00:00"
```

- 时间部分必须写 `00:00:00`（起租日/到期日均为零点时间戳，`LE/GE` 比较恰好做到两端闭区间包含）。
- 默认**不加** `铺位类型` 筛选（正铺+多经都要）；用户明确指定单一类型时才加。
- 默认**不加** `合同状态` 筛选；合同状态仅作为输出列展示。
- 输出为 14 列纯明细临时表（门店名称,合同号,铺位号,租户名称,品牌,业态,主品类,楼层,计租方式,计租面积,起租日,到期日,铺位类型,合同状态），无汇总；最终输出表后续另行提供。

### 为什么不用"合同状态=执行中"（口径验证记录，2026-09-04）

| 口径 | 弘阳家居南京江北店 2026-08-31 结果 |
|---|---|
| ① 状态=执行中 + 日期窗口（全类型） | 625 份 |
| ② ① + 正铺 | 473 份 |
| ③ **正铺 + 日期窗口（本 skill 口径）** | **504 份，与《ADS-租赁分析-出租率-铺位-日快照》8/31 的 504 个唯一合同号完全一致、双向零差异** |

原因：合同状态是**取数快照时点**的状态值。到期日恰好等于基准日的合同，在次日之后的快照中状态已翻转为"已到期"，若加状态条件会漏掉这些基准日当天仍在执行的合同（实测漏 17 份）；"未执行"（铺位已被占用）、"锁定中"（续约锁定）等状态同理。日期窗口口径才是"基准日当天在执行"的准确判定。

### 504 份的状态构成（参考）

执行中 473 / 已到期 19（其中 17 份到期日=8/31）/ 未执行 8 / 锁定中 2 / 已终止 2。

## 未执行合同（模式 B，收入/回款预测基表）判定口径

**未执行 = 起租日 > 基准日**（`起租日 GT <基准日> 00:00:00`，开区间），即已签约但尚未起租的合同。

筛选条件（guancli ds preview --filter，AND 组合）：

```
--filter "门店名称 EQ <门店全称>"
--filter "起租日 GT <基准日> 00:00:00"
```

- **附加条件：起租日 < 到期日**（剔除起租日≥到期日或日期缺失/无效的异常记录）。guancli `--filter` 只支持「列名 操作符 常量值」，不支持字段间比较，因此该条件由 `make_report.py --mode future` 在本地过滤，脚本会打印剔除行数与明细。
- 同样**不加** `合同状态` 筛选（未起租合同状态多为"未执行"，也可能有"锁定中"等，全部保留）。
- 同样**不加** `铺位类型` 筛选，默认正铺+多经。
- 输出为**无汇总的纯明细临时表**，输出列与模式 A 统一（14 列：门店名称,合同号,铺位号,租户名称,品牌,业态,主品类,楼层,计租方式,计租面积,起租日,到期日,铺位类型,合同状态），直接作为后续收入和回款预测的中间基表；最终输出表后续另行提供。

## 合并清单续签判定（执行+未执行合同清单）

- 续签 = 同一（门店名称, 铺位号）在在执行合同与未执行合同中同时存在。
- 在执行合同（原合同）：`是否续签`=是，`续签描述`="合同已续签，续签合同号：xxx"；未执行合同（新合同）：`是否续签`=否，`续签描述`="该合同为续签合同，续签自合同号：xxx"；其余合同：`是否续签`=否，`续签描述`为空。
- 同一铺位多份合同时按起租日升序全部列出（顿号分隔）；铺位号为空不参与匹配。
- 该逻辑无法用 guancli filter 表达，由 `scripts/merge_contracts.py` 在本地处理；不设合同来源列（后续关联的应收明细均为存量收入）。

## 已知环境限制

- `guancli ds execute-sql` 在该环境报 Spark `PARSE_SYNTAX_ERROR`，**不可用**；一律用 `ds preview --filter`。
- `ds preview` 无 `-o` 参数，用 shell 重定向 `> /tmp/xxx.json` 落盘。
- preview `--limit` 上限给 2000；若结果行数 ≥ limit 需提示结果可能被截断并分批处理。
- 数据集是当前快照：基准日距快照日越远，"已终止/已到期"的历史状态越无法回溯，报告需注明快照更新时间。
