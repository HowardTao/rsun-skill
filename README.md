# rsun-skill

技能集合仓库：存放可分发到 AI 客户端（WorkBuddy / CodeBuddy）的数据技能包，当前包含 1 个技能，后续会持续添加。

## 目录结构

```
rsun-skill/
├── README.md              # 本文件（仓库总览）
├── .gitignore             # 全局忽略 __pycache__/ 与 *.pyc
└── <技能目录>/             # 每个技能一个独立目录
    ├── README.md          # 该技能的详细说明（简介/安装/使用/贡献）
    ├── SKILL.md           # 技能执行流程与口径（AI 加载用）
    ├── PROJECT_MEMORY.md  # 技能级项目记忆（背景/约定/决策/变更日志）
    ├── references/        # 参考资料（字段口径、别名映射等）
    ├── scripts/           # 可执行脚本
    └── output/            # 运行产物（不入库）
```

## 当前技能列表

| 技能 | 目录 | 简介 |
|---|---|---|
| 商业收入及回款预测 | `商业收入及回款预测/` | 按基准日与门店从观远 BI 拉取租赁合同及应收明细，生成收入/回款预测的中间临时表 |

详细说明见各技能目录下的 `README.md` 与 `SKILL.md`。

## 添加新技能的约定

1. 在仓库根目录新建独立技能目录，目录内至少包含 `SKILL.md` 与 `README.md`；涉及多轮任务的技能建议维护 `PROJECT_MEMORY.md`。
2. 技能自包含：脚本、参考资料、文档均放在本技能目录内，不跨目录引用；运行产物输出到本技能目录的 `output/`（不入库）。
3. 新增技能后，在上方「当前技能列表」登记一行（技能名 / 目录 / 一句话简介）。
4. 技能功能发生调整时，同步更新该技能目录下的 `README.md` 与 `SKILL.md`，并在其 `PROJECT_MEMORY.md` 变更日志登记；根 README 的技能列表仅在新技能增删时更新。
5. 公共工具（如 guancli 认证、Python 解释器路径约定）在各技能文档内自行说明，仓库不设全局配置。

## 通用约定（对所有子项目生效）

- 提交信息用中文简要描述变更内容；`output/` 产物与 `__pycache__/`、`*.pyc` 不入库。
- 涉及业务口径的变更须先与负责人确认，再修改代码与文档。
- 文档与代码保持一致：改功能必须同步改文档。
